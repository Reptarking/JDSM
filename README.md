# JDSM

Página personal/profesional de Juan Diego Saquicoray.

## Estructura

- `index.html`: contenido principal de la landing.
- `styles.css`: estilos visuales, responsive y layout.
- `script.js`: interacción del menú móvil y año automático.

## Publicación en GitHub Pages

1. Entra a **Settings** del repositorio.
2. Ve a **Pages**.
3. En **Build and deployment**, selecciona:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
4. Guarda los cambios.

La página quedará publicada con la URL de GitHub Pages del repositorio.
